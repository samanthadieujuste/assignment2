8. Inheritance is when child class takes the attributes and methods of a parent class. Polymorphism allows objects of different classes to respond to the same method or action in different ways. 9.In the Dictator and Lieutenants workflow, there is one central repository controlled by a dictator that merges changes from lieutenant repositories. Lieutenants manage and resolve conflicts for groups of developers before sending their changes to the dictator. In the Integration Manager workflow, each developer has their own public repository and submits changes to an integration manager that handles integration and conflict resolution.

10. A team of 100 developers would benefit from the Dictator and Lieutenants workflow because the workload is distributed among multiple lieutenants instead of requiring everyone to push changes directly to one central repository. Each lieutenant manages a smaller group of developers and resolves conflicts within that group before sending changes to the dictator. This makes collaboration more organized and helps prevent the central repository from becoming overwhelmed with conflicts from 100 developers.
